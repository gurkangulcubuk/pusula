# PUSULA

Kişisel planlama ve bilgi pusulası. Telefon ve tablette uygulama olarak kurulup internetsiz çalışan bir web uygulaması (PWA).

- **Adres:** https://gurkangulcubuk.github.io/pusula/
- **Kurulum:** Adresi Android'de Chrome ile aç, ⋮ menüsünden **Uygulamayı yükle**'yi seç.
- **Veriler:** Görevler, notlar ve diğer veriler bu depoda değil; cihazda ve (açıksa) kullanıcının Google Drive'ındaki gizli uygulama klasöründe saklanır.
- **Güncelleme:** `main` dalına gönderilen her değişiklik GitHub Pages ile yayına çıkar. Uygulama açılınca "Yeni sürüm hazır → Güncelle" bildirimi gelir.
  - Her sürümde `app.js` içindeki `VERSION` ve `sw.js` içindeki `CACHE` birlikte artırılmalıdır.
